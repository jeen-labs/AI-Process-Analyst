# Employee Offboarding Process Checklist

## 📋 Pre-Offboarding Phase

- [ ] Resignation/termination notice received
- [ ] HR notified within 24 hours
- [ ] Manager notified
- [ ] IT notified
- [ ] Facilities notified

## 🔄 Offboarding Workflow

### Day 1: Notification & Documentation

START
│
├─ Resignation Received?
│ ├─ YES → Proceed to Exit Interview Scheduling
│ └─ NO → ⚠️ Escalate to HR (Missing Documentation)
│
├─ Exit Interview Scheduled?
│ ├─ YES → Conduct Exit Interview
│ └─ NO → Reschedule (Within 48 hours)
│
└─→ Documentation Complete?
├─ YES → Proceed to Day 2
└─ NO → Return for completion

EXIT CRITERIA:
□ Exit interview completed
□ Resignation letter signed
□ NDA/confidentiality agreement reviewed
□ Final settlement letter prepared

### Day 2: Asset Recovery

START
│
├─ IT Equipment Returned? (Laptop, Phone, Access Cards)
│ ├─ YES → Verify equipment condition
│ │ ├─ PASS → Update asset inventory
│ │ └─ FAIL → Damage report (⚠️ HR notified)
│ └─ NO → Request return within 5 days
│
├─ System Access Revoked?
│ ├─ Email: [REVOKED]
│ ├─ VPN: [REVOKED]
│ ├─ Corporate Apps: [REVOKED]
│ └─ Shared Drives: [REVOKED]
│
├─ Documents Transferred?
│ ├─ YES → Transfer to manager/team
│ └─ NO → Send reminder
│
└─→ Assets Recovered?
├─ YES → ✅ Proceed to Day 3
└─ NO → 🔴 Escalate to Security

⚠️ BLOCKER: Missing equipment → Security investigation

### Day 3: Final Processing

FINAL APPROVAL CHECKLIST
═══════════════════════════
□ HR Review Complete
□ Final Payroll Calculated
□ Benefits Termination Processed
□ Records Updated in HRIS
□ Reference Contacts Documented
□ Security Clearance Removed

▸ IF ALL CHECKED: Send Final Clearance Certificate
▸ IF ANY MISSING: Return to relevant department

POST-OFFBOARDING:
├─ Alumni Status Created
├─ Exit Survey Sent (30 days later)
└─ Process Audited (90 days)

### ⚠️ Exception Escalation Matrix

| Exception            | Escalation Path    | Time Limit |
| -------------------- | ------------------ | ---------- |
| Missing resignation  | HR Director        | 48 hours   |
| Unreturned equipment | Security Manager   | 24 hours   |
| Unauthorized access  | IT Security Lead   | Immediate  |
| Payroll disputes     | Finance Controller | 72 hours   |

### 🎯 Success Indicators

SUCCESS = All checkboxes checked + No escalations + Clearance issued
PARTIAL = Checkboxes incomplete → Hold clearance
FAILURE = Escalation required → Hold process
